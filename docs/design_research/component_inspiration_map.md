## 1. Overview & Adaptation Rationale

To develop a coherent, world-class medical screening interface without copying proprietary code or branding, this document maps every proposed frontend component in the **EYERIS** architecture to its clinical/commercial reference system. For each component, the specific design inspiration, limitations of the original, and EYERIS's specialized adaptations are defined.

## 3. Design Synthesis: A Unified Design Language

Rather than visually disjointed components, all EYERIS elements share a single design token architecture:
1. **Unified Surface Geometry**: Consistent 8px border radii (`rounded-lg`), subtle 1px border dividers (`border-slate-800`), and dark elevated slate backgrounds (`#111827`).
2. **Unified Interaction Cues**: Subtle blue focus rings (`#3B82F6`), smooth 150ms transitions on hover, and clear ARIA accessibility labeling on all interactive viewport controls.
3. **Information Density Balance**: Generous 24px padding around primary diagnostic cards to prevent visual fatigue, paired with tight, high-density tabular alignments for quantitative metrics and coordinates.
